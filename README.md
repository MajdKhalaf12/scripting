# Scripting

A collection of Python automation and security scripting projects.

## Setup

From the repository root:

```bash
python -m venv .venv
source .venv/bin/activate   # Windows: .venv\Scripts\activate
```

Install dependencies per project (see each folder’s README).

## Projects

| Directory | Description |
|-----------|-------------|
| [nmap-obsidian/](nmap-obsidian/) | Convert Nmap XML scans into an incremental Obsidian vault: per-host notes, network graph, asset roles |

## Legal use

Scripts that probe networks or hosts are for **authorized testing only** (systems you own or have written permission to assess). See each project README for details.
